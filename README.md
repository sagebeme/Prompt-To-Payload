# Prompt to Payload

A four-level course that takes learners from everyday AI prompting to prompt injection, red-teaming and defence, taught through relatable stories and real public incidents.

## Levels

1. **Foundations**: how LLMs work, anatomy of a good prompt, specificity, iteration.
2. **Techniques**: few-shot prompting, step-by-step reasoning, structured output, system prompts, prompt chains.
3. **Real systems**: APIs, tools and agents, RAG, testing prompts.
4. **Security**: the OWASP LLM Top 10 and MITRE ATLAS, direct and indirect prompt injection, data exfiltration, defence in depth, red-teaming.

The course ends with a capstone project: build an agent, red-team a partner's, report what you find, then harden your own.

## Viewing

The whole course is a single `index.html` with no build step. Open it in a browser, or serve it with GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder).

Module progress is saved in the viewer's browser (localStorage).

## Ethics

Level 4 teaches attack techniques so people can defend against them. Only test systems you own or have written permission to test, practise on purpose-built labs, and report vulnerabilities privately.
